# CodeMan99 Tap

## How do I install these formulae?

`brew install codeman99/tap/<formula>`

Or `brew tap codeman99/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "codeman99/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
